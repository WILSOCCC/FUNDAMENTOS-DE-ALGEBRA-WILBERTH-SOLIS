    Casos de factorización (Haz clic aquí para mostrar u ocultar los casos)

    • Factor común: 12x² + 18x = x(12x + 18)
    • Trinomio cuadrado perfecto: a² + 2ab + b² = (a + b)(a + b) = (a + b)²
      a² - 2ab + b² = (a-b)(a+b) = (a-b)²
    • Diferencia de cuadrados perfectos: x² - 16 = √x² = x, √16 = 4. x² - 16 = (x - 4)(x + 4)
